# SkyCast Weather Application

A modern, responsive weather forecasting web application that provides real-time weather information with an intuitive user interface.

## 🌟 Features

- **Real-time Weather Data**: Get current weather conditions for any location
- **Interactive Maps**: Explore weather patterns with interactive Leaflet maps
- **Multi-language Support**: Available in multiple languages for global accessibility
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional interface built with Bootstrap 5
- **Safety Features**: Weather safety information and alerts
- **Theme Support**: Light and dark mode options

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (comes with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AsmaaMostafaTech/skycast_team.git
   cd skycast_team
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:3000`

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **UI Framework**: Bootstrap 5
- **Mapping**: Leaflet.js
- **Icons**: Font Awesome
- **Backend**: Node.js with HTTP server
- **APIs**: OpenWeatherMap API (for weather data)

## 🌐 API Configuration

To use weather data, you'll need to sign up for an API key at [OpenWeatherMap](https://openweathermap.org/api) and configure it in the application.
